Business Data Extractor

A Python script that extracts structured information from HTML response files and exports it to CSV.

Features

- Extract Business Name
- Extract Email Address
- Extract Phone Number
- Extract Nature of Business
- Extract Applicant Name
- Extract Address

Technologies Used

- Python
- Regular Expressions (Regex)
- CSV
- Data Processing

Example Output

Business Name| Email| Phone
ABC Traders| abc@example.com| 9876543210
